# Clinic Guide 🏥

Clinic Guide is a patient-focused website designed to help patients easily access clinic information and request appointments.

## Features

- 🏠 Home page
- 🩺 Services page
- 📖 Clinic Guide page
- 📅 Appointment page
- 📞 Contact page
- ✅ Form validation
- 🎨 Responsive and user-friendly design
- ✨ JavaScript animations and interactions

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Pages

- **Home** – Introduction to Clinic Guide
- **Services** – Information about available clinic services
- **Clinic Guide** – Helpful information for patients
- **Appointments** – Patients can request an appointment
- **Contact** – Clinic contact information and contact form
